03Is it an enquiry?

Every chat gets one of seven labels. Only one of them creates an enquiry: New Enquiry.

Enquiry

Anyone asking about a trip.

"Do you have packages for the Six Nations?"

Check the details, then mark as New Enquiry.

Information Request

A question about how things work.

"How do I pay?" "How does this work?"

Not a new enquiry. Don't mark as New Enquiry.

Follow Up

A client chasing someone they've already dealt with.

"I haven't heard from my consultant."

Not a new enquiry. Don't mark as New Enquiry.

Feedback

A client sharing a thought or suggestion about their experience.

"It would help to get the itinerary a bit earlier next time."

Not a new enquiry. Don't mark as New Enquiry.

Compliment

A client who is happy and wants to say so.

"Just wanted to say thanks for a great trip."

Not a new enquiry. Don't mark as New Enquiry.

Complaint

A client who is unhappy about something. Call it what it is; don't label a complaint as Feedback.

"Nobody has come back to me about my refund and I'm not happy."

Not a new enquiry. Escalate straight away to Melissa or Bruce. A complaint needs an immediate update, never a 24-hour turnaround.

Added More Info to Enquiry

Only for a chat you've already resolved as New Enquiry, then reopened to get more details from the client.

You created the enquiry, reopened the chat to ask for travel dates, and the client has now sent them.

Close the chat with this label once the extra details are captured. Never close it as New Enquiry again, as Follow Up, or as any other label. See adding more details.

Why it matters

Marking a chat as New Enquiry creates an enquiry in Freshsales automatically. If any other chat gets marked by mistake, including one you've reopened, it creates an enquiry that shouldn't exist and clutters the pipeline.

04Check the details

Before you mark a chat as New Enquiry, capture the client's details in Edit contact info

The enquiry in Freshsales is built from what's on the contact. If the details aren't captured here first, the enquiry arrives incomplete and someone has to fix it by hand.

  1. 1
    Open Contact info and click EditIt's in the panel on the right of the chat.
  2. 2
    Capture what the client has told youWork through the fields below. Use what's in the chat; don't guess.
  3. 3
    Save, then set the Type to New EnquiryThis is what triggers the enquiry to be created in Freshsales.

Need more details? Reopen, then close as Added More Info to Enquiry

If you've created the enquiry and still need something from the client, such as dates or numbers travelling, use the chat itself. Don't capture the enquiry by hand.

  1. 1
    Resolve as New EnquiryWith everything you have so far filled in on the side in Edit contact info. This creates the enquiry.
  2. 2
    Reopen the chat straight awayAsk the client for what's missing.
  3. 3
    Add the new detailsUpdate Edit contact info with what the client sends.
  4. 4
    Close with Added More Info to EnquiryThis tells everyone the chat added to an existing enquiry, not that it's a new one or a follow up.
Don't work around the label

Don't create the enquiry yourself and close the chat as Follow Up (or anything else) to avoid a duplicate. Use New Enquiry to create it, and Added More Info to Enquiry for everything after that. That way the chat history shows exactly what happened.

07Why we don't delete chats

Every chat is part of the client's history. The only chats we delete are spam.

Every chat, resolved or not, stays on the client's record in Freshsales under Conversations, Chats. Anyone picking up that client can see everything they've asked us, when, and how it was handled, without having to ask them again.

Keep itEvery real chat, even short ones like "hi there" or a single emoji. They show the client's full journey with us.
Delete itSpam only. If you're not sure whether it's spam, leave it and flag it.
Gone is goneDelete a chat and that part of the client's history goes with it.

08Flagging issues

If something looks wrong, say so

Who to tagTag Robyn and Bruce on anything that looks wrong or stuck. Complaints go to Melissa or Bruce.
If there's a delaySpeak up straight away. Don't wait for the next check or assume someone else has seen it.
It might be a process gapA "delay" isn't always a system problem. Sometimes the process just doesn't cover the situation yet, and raising it is how we fix that.
Tip

Resolve first, reopen if you need more. Resolve the chat as New Enquiry to create the enquiry, then reopen it straight away if you still need more information from the client. Once you have it, close the chat as Added More Info to Enquiry.

Reopening a chat is quicker than capturing the enquiry by hand, and the client's details are already there.

09Quick answers

The questions that come up most

The client is asking how to pay. Is that an enquiry?

No. That's an Information Request. Don't mark it as New Enquiry.

The client says they haven't heard from their consultant. Is that an enquiry?

No. That's a Follow Up. They're already in the system, so don't mark it as New Enquiry.

The client is giving feedback about their trip. Is that an enquiry?

No. Label it as Feedback, Compliment or Complaint. If they also ask about a new trip in the same chat, treat it as an Enquiry.

Is it Feedback, a Compliment or a Complaint?

Happy client saying thanks: Compliment. A thought or suggestion: Feedback. Unhappy and something needs putting right: Complaint, escalated straight away to Melissa or Bruce.

I've resolved the chat but still need the client's dates. What now?

Reopen the chat and ask. The enquiry has already been created. Once the client replies, add the details and close the chat as Added More Info to Enquiry.

Can I create the enquiry myself and close the chat as Follow Up so it doesn't duplicate?

No. Fill in the details on the side and resolve as New Enquiry to create it. If you need more, reopen and close as Added More Info to Enquiry. That label is there so we can see exactly what happened.

Can I delete a chat?

Only if it's spam. Every other chat stays on the client's record under Conversations, Chats, so the team can see their full history.

What if Interested Event is left on "Choose any"?

The enquiry comes through without the event it's about. Set it before you mark the chat as New Enquiry.

The client sent a voice note or a screenshot and the bot replied "I don't understand". What do I do?

Take the chat over and reply yourself. Then flag the example to Robyn and Bruce.

I couldn't check during my shift. Does it matter?

Yes. Covering both shifts is what keeps clients from waiting on a stuck bot or a closed chat. If you can't cover your shift, let the other person know, and if the roster isn't working, say so.
